# אלמוג אלון — תיק עבודות

אתר תיק עבודות של אלמוג אלון, ספר. עמוד אחד, בעברית, מותאם קודם כול לנייד.
הקישור נועד לשבת ב-bio של האינסטגרם.

**כתובת האתר החי:** https://mlwn930-sudo.github.io/ALMOG-ALON-/

---

## מה צריך לדעת כדי לערוך

### להחליף מספר טלפון
פותחים את `js/app.js`. בשורות הראשונות:

```js
phone: '0544478819',
```

כותבים את המספר כמו שמחייגים אותו בארץ. מהמספר הזה נבנים **גם** כפתור החיוג,
**גם** קישור הוואטסאפ **וגם** המספר שמוצג על הכפתור — אין צורך לעדכן בשלושה מקומות.

### להחליף את קישור האינסטגרם
באותו מקום, השורה `instagram:`.

### להוסיף תמונת עבודה
1. שומרים את התמונה בתיקייה `assets/work/` בשם `work-7.jpg`.
2. ב-`index.html`, בתוך `<div class="works__grid">`, מעתיקים בלוק `<figure class="card">` קיים ומשנים בו:
   - `src` — שם הקובץ החדש
   - `alt` — תיאור התמונה
   - `width` ו-`height` — המידות האמיתיות של הקובץ
   - `data-tags` — `men` / `kids` / `design` (אפשר כמה, מופרדים ברווח)
   - את הטקסט ב-`<figcaption>`

### לשנות טקסט
הכול נמצא ב-`index.html`, מחולק למקטעים עם הערות בעברית: HERO, הסיפור, העבודות, השירותים, למה אלמוג, צור קשר.

### לשנות צבעים
ב-`css/style.css`, בבלוק `:root` בראש הקובץ. כל הצבעים מוגדרים שם פעם אחת.
